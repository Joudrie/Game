# Working on this game (notes for the next Claude session)

A mobile-first third-person action game in three.js (GTA / Red Dead / Watch Dogs / Assassin's Creed feel, Lego Star Wars fun). Characters come from the owner's custom Lego figures and paintings. Read `VISION.md` (what the game is: Vanguard missions, "Hitman, but loud"), `CHANGELOG.md` (what exists, newest first), `BACKLOG.md` (what's next, in sections), `IDEAS.md` (every game and idea the owner has named, with what's built) and `ASSET_GUIDE.md` before starting.

## How the owner works
- **Push and merge everything.** Branch `claude/<topic>`, open a PR to `main`, merge it.
- **Update the play link after every change.** It's the claude.ai artifact https://claude.ai/artifact/E9adumTVxy2TBMT8bVxEfS. Publish `dist/index.html` to that URL; read it first in a new conversation.
- **Find, don't build.** Look for free public assets (GitHub, Printables, Sketchfab, OpenGameArt, Poly Pizza, Quaternius, KayKit) before writing code. Record each one in `CREDITS.md` and in a `SOURCE.txt` next to the file. Check the licence; never ship unlicensed files.
- **Variety.** Several variants of every animation, selectable in Menu → Moves and rotated in play.
- **Report problems back.** T-poses, freezes and stuck states are caught by the in-game watchdog and reported. Take reports the owner pastes seriously and fix the root cause.
- **Keep the docs current.** Add a `CHANGELOG.md` entry for every version (bump `BUILD` in `src/game2.html`), and keep `BACKLOG.md` in sections.
- **PC first (owner, v21).** Mouse and keyboard are the real platform. Phones only need to load the game and look right for a quick look (a friend opening a texted link): keep the layout working at 375 px, but new mechanics don't need full touch controls.

## Build and test
- **Game source:** `src/game2.html`, a single file with the module script inside. `python3 tools/build2.py` embeds the models, animations and the jetpack OBJ from `build/` and `assets/`, and writes:
  - `dist/index.html`, for the artifact
  - `dist/preview2.html`, for local tests, which loads three.js from `/three/`
- **Setup:**
  1. `npm install`
  2. `mkdir -p dist/three && cp -r node_modules/three/build node_modules/three/examples dist/three/`
  3. Serve with `python3 -m http.server 8766 --bind 127.0.0.1 --directory dist`, run in the background with a long timeout.
- **Tests:** `node tools/testNN-*.mjs` (Playwright, Chromium at `/opt/pw-browsers/chromium` with swiftshader flags; see any test).
  - Headless runs at about 8 fps, so use the `__game.advance(seconds)` hook instead of real waits.
  - Test hooks live on `window.__game`: `setGear`, `selectSlot`, `fillEnemies`, `moveEnemy`, `damageEnemy`, `shootAt`, `setKey`, `advance`, `startLoot`, `startReload`…
  - Main tests: test17 (enemies), test18 (combat), test23 (dual combos), test24 (The Second, skipped while shelved), test25 (performance), test26 (dismemberment), test27 (batch 1), test28 (guns), test29 (Force, saber, movement), test30 (enemy minds, health, ragdoll, takedowns, cover), test31 (courtyard, mission, attachments, creative), test32 (throwables, saber moves, swing, Mission 2), test33 (specials, sneak, cloak, falls, presets, Mission 3), test34 (v30 play-test fixes), test35 (world, soldier looks), test36 (energy shields), test37 (v32 audit fixes), test38 (v33 audit batch 2), test39 (hero look), test40 (pause and settings), test41 (roads), test42 (sounds), test43 (civilians), test44 (barrels, mines, score), test45 (voices), test46 (hills: sprint everywhere, on the ground), test47 (specials vs dash and the Force; camera over hills), test19 (v14 feel), test20 (loot), test21 (inventory), test22 (reload), test9 (menus and gear).
  - `tools/sheet17.mjs` makes animation contact sheets. Use them to check clips by eye before adding them.
- **Animation pipeline:** everything is retargeted onto the UE5-mannequin skeleton of the Quaternius Superhero.
  - `tools/retarget.mjs`: `retarget` for sources with a T-pose; `retargetDir` for rigs that don't have one.
  - Bake scripts: `tools/bake_*.mjs` (Mixamo names: `mixamoMap('mixamorig')`; CMU BVH; KayKit).
  - Output clips go into `build/extra.json` (`clips` + `library`).
  - Run `python3 tools/trim_snap.py build/extra.json` after adding one-shot clips; it removes the snap-back last frame.
  - `tools/pack.mjs` repacks the Quaternius UAL libraries (the `KEEP` lists).
  - Some scripts have `/home/user/game` hard-coded as the path; adjust if the clone lives elsewhere.

## Credentials in the environment
These are added as **API credentials** in the cloud environment. The proxy injects the header; the token is never visible. Don't ask for tokens in chat.

- **Sketchfab** (`api.sketchfab.com`, `Authorization: Token …`)
  - Search: `GET https://api.sketchfab.com/v3/search?type=models&q=<words>&downloadable=true&license=cc0|by`
  - Download: `GET https://api.sketchfab.com/v3/models/<uid>/download` returns signed `glb`/`gltf` URLs, which need no auth.
  - Check each model's licence and author, and credit it. Skip models ripped from commercial games (for example "Fortnite rip").
- **Hugging Face** (`huggingface.co`, `*.hf.space`, `Authorization: Bearer …`)
  - Use it to turn the owner's paintings into 3D. Image-to-3D Spaces include `microsoft/TRELLIS`, `tencent/Hunyuan3D-2` and `stabilityai/TripoSR`; call them with `gradio_client`.
  - First character: **The Second**. The front, side and back turnaround images are in the owner's earlier chat; ask them to add the images to `assets/characters/the-second/` if they aren't in the repo.
- **Mixamo** (`www.mixamo.com`, `Authorization: Bearer <localStorage.access_token>`). This API is **unofficial** and the token **expires after about a day**. **As of v19 the owner can't sign in to Mixamo at all** (account pages are broken), so every authorized call returns 401. Search and product details still work without auth. Don't plan around Mixamo; look for free sources instead. `tools/mixamo_fetch.mjs` does the whole export if a token ever works.
  - Also send `X-Api-Key: mixamo2`. Search works without auth: `GET /api/v1/products?page=1&limit=48&type=Motion%2CMotionPack&query=<words>`.
  - Export flow, as the site does it (unverified here):
    1. `GET /api/v1/products/<id>?similar=0&character_id=<char>` for `details.gms_hash`
    2. `POST /api/v1/animations/export` with `{character_id, product_name, type:'Motion', preferences:{format:'fbx7_2019', skin:'false', fps:'30', reducekf:'0'}, gms_hash:[…]}`
    3. Poll `GET /api/v1/characters/<char>/monitor` until `status: 'completed'`; `job_result` is the download URL.
    4. Get the owner's default character id from `GET /api/v1/characters/primary`.
  - Convert the FBX, for example with the `fbx2gltf` npm binary, then bake with `mixamoMap('mixamorig')`.
  - Wanted clips: see `ASSET_GUIDE.md` (sword draw and sheath, sword and dual combos, pistol locomotion, rifle pack, deaths by cause, slides, flips, flying).

## Where things stand (v22)
- **Movement:** classes (light, Force, heavy), slides with momentum, infinite and double jumps, grapple (also onto enemies), jetpack (Mandalorian model), ground pound.
- **Combat:** five-hit saber combo, four dual-saber combos (Moves → Dual saber combo; left-hand hits are mirrored clips from `tools/bake_mirror.mjs`), fists combo, pistol with aim pitch, 12-round magazine, reload and dropped magazines, Force push, grenades, saber blocking bullets.
- **Dismemberment (v22):** `bladeCuts()` sweeps each lit blade frame to frame against the soldiers' body segments (`CUTS`). Head, torso and legs kill, severed there (`e.cut` → `goreOnDeath`); arms and hands come off and he lives (gun hand: `dropGun`, `e.unarmed`, flees). `updateBlood` handles stump spurts and splats. Test: test26.
- **Bone edits after the mixer (v23):** always go through `mixHero()`. It restores every bone to last frame's mixer output first, because three.js skips rewriting unchanged tracks and post-mix edits would otherwise pile up (the stuck-pistol bug).
- **Guns (v24):** the `GUNS` table (pistol, ak, shotgun, sniper: damage, rate, pellets, spread, zoom, sound, reload). `gunKind` and `G()` are the gun in hand; the `pistol` variable is its object in `guns`. Hotbar items carry `gun:`. Rifles in hand are placed by `holdRifle()` (stock at the shoulder, both hands by `ikArm`); the pistol uses the hand mount. Per-gun magazines are in `ammo.mags`.
- **Enemy fire (v24):** blaster bolts are projectiles (`shootBolt`/`updateBolts`): guard covers front and sides, a block within 0.3 s of arrival parries, and `guardLoad` > 8 breaks the guard. AK soldiers fire bullet bursts (`enemyBullet`). Sounds: `sfx(name, at)`, clips in `build/sfx` from `tools/make_sfx.sh`. The build was 15.72 MB in v24; v27's clip packing brought it to 14.6 MB.
- **Force and saber (v25):** `forceMode()` is when the Force item is active: `forcePull` / `chokeStart` / `zapStart`, all in `updateForce`, with the marker `forceRing`. `saberThrow` / `updateThrow` fly `sabers[0]`, and `bladeCuts` cuts with it. `saberFx` handles the trail, the PointLight per blade, world scorch and sparks (`scorch`), and the hum. The Saber + blaster item is `blasterMode()` / `fireBlaster` (heat). Wall run: `updateWallRun` / `wallKick`. Force class has `tripleJump`.
- **Enemies that think (v26):** each soldier has `e.mind` (`patrol`, `panic`, `spot`, `combat`) on top of the physical `e.state`. `calmUpdate` handles patrol and noticing (`seesPlayer`, meter `e.sus`, marks `setMark`), the shout (`raiseAlarm`), `witnessDeath` (panic) and `noise(at, r)` (radii in `HEAR`). In combat, soldiers shoot only with line of sight (`e.los`). Difficulty is `DIFF` / `DF()` (hits, see, acc, react, smart); headless tests (`navigator.webdriver`) default to Sandbox so older suites aren't hurt.
- **Player health and death (v26):** `hp` (0..1), `hurtPlayer` / `hurtHits`, regen in `updateHealth`. `playerDie` makes a corpse from `playerTemplate` (`makeCorpse`), ragdolls it, and severs limbs for your own grenade. `deadStep` runs the world while dead; `respawn()`.
- **Ragdoll (v26):** Verlet, in `makeRag` / `stepRag` / `driveRag` (15 points, sticks, joint minimums, box and ground collision, sleeps when still). It steers the pelvis and chest by frames and the limbs by aiming. Enemies use it for `RAG_DEATHS` (`ragEnemy`); `shoveBody` kicks it.
- **Takedowns and cover (v26):** `findTakedown` / `startTakedown` (F or click behind an unaware soldier). Cover is `enterCover` / `coverStep` / `leaveCover` on Q (`cover.u` along the face, `peek`, `edge`, `low`); blind fire adds spread in `firePistol`.
- **Courtyard and breaking (v27):** `buildCourtyard()` (after `buildCity`, at `COURT`) adds blocks with `mat` (`stone`, `wood`, `glass`) and `hp`. `hitBlock` / `breakBlock` / `castShot` (shots walk through glass and broken wood) / `breakAround` (blasts) / `updateDebris`; `removeBlock` keeps `blocks` and `blockMeshes` in step. `collideCircle.block` tells a thrown soldier what he hit.
- **Missions (v27):** `MISSIONS`, `startMission` / `spawnWave` / `updateMission` / `completeMission` / `endMission`. The sandbox inventory is saved in `mission.saved` (and `localStorage['inv-sandbox']` in case of a reload). Earned gear is `kept` (`localStorage.kept`); the grapple is gated in missions. Enemy kinds come from `spawnEnemy(at, kind, mind)`, with `e.hold` for snipers (`sniperLaser` / `sniperShot`).
- **Attachments and creative (v27):** `ATT`, `gunAtt` (per gun kind, `localStorage.gunatt`), `applyAtt` hangs the models in a group named `att` (stripped from soldiers' copies), and `gunZoom()`. The creative catalogue is `renderCreative` / `addFromCatalog`; `renderAttFor` handles the inventory attachment row.
- **Build packing (v27):** `tools/build2.py` stores each clip's shared key times once (`T`) and collapses constant tracks; `boot()` puts the times back before `AnimationClip.parse`.
- **Throwables and moves (v28):** `NADES` (the item for each kind), `lastNade`, `makeThrowable`, `throwGrenade(kind)`, `stickTo` (sticky: `g.stuck`, `g.fuse`), `firePatch` / `updateFires` / `setAlight` / `burnUpdate` (`e.burning`), and `teleportTo`. Dash strike is `dashTarget` / `startDash` / `updateDash`; yank is `grapple.yank` (from `rmbHeld`) and `yankEnemy`; finishers go through `isStunned` in `findTakedown`. Swing is `grapple.swing` / `swingGrapple` (setting `gadgets.swing`). Mission 2 is `survive` in `MISSIONS` (`survivalTick`, `edgeSpot`); the jetpack in missions needs `kept.has('jetpack')`.
- **Special soldiers, stealth, presets (v29):** `makeSpecial(e, 'jugg'|'shield'|'duel')` / `spawnSpecial`. `guardAgainstBlade` (in `bladeCuts`) and `absorbHit` (top of `damageEnemy`) decide what the field, the shield or a duellist stops; `duelUpdate` is the duellist's fight. Sneak is `walkToggle` (`sneaking()`, `walkClip()`). Holocloak: `cloakT` / `startCloak` / `setHeroLook`. Falls: `fallDamage` in `land()`, and a knocked soldier landing at vy < -14.5 dies. Blue berry: `fallSafeT`, `worldPickups`. Presets: `moveMode` ('mix'|'fav'; favourite = `pool[slot][0]`), `setFavourite`, `savePack` / `loadPack`. Mission 3: `stealth` in `MISSIONS`, with `stealthSetup` / `stealthTick` / `tryObjective` / `failMission`. Run a single test with `tools/serve.sh node tools/testNN.mjs`.
- **Play-test fixes (v30):** `emixPost` (edit enemy bones after the mixer safely), `enemyAim`, `chokePose`, `grappleRepelled`, the throw arc (`updateArc`, `windUpThrow`, `throwWind`), `setAura`, `BUILDS` / `applyBuild`. Fire is particles (`initFireFx` / `emit` / `stepParticles`; textures in `window.__ASSETS.tex`) with 3 pooled lights (**never add lights mid-game: it recompiles every material**). The rifle reload is in `holdRifle` (`pistol.magPt`). Test: test34.
- **World and soldier looks (v31):** `dressWorld()` (called in `boot()`) puts a Kenney building from `build/world_buildings.glb` over every block with `b.city`, resizes the block's box and hidden mesh to it (`b.model`), then `scatterNature()` (instanced grass, flowers, rocks, trees with trunk blocks marked `nature`, the stone path) and `buildClouds()` / `updateClouds`. Packs come from `node tools/pack_buildings.mjs` (meshopt, so the loader has `setMeshoptDecoder`). Soldiers: `dressSoldier(e)` picks a uniform from `UNIFORMS` and a tone from `SKIN_TONES` (recoloured copies of the vertex colours, `soldierGeo`, stored in `e.skinGeo`) and scales the Head to 0.86; `randomLoadout()` mixes pistol, ak, ar and shotgun. Test: test35. Player shield: `pshield`, `shieldUp()` / `shieldStops(from)` / `shieldHit` / `holdShield(dt)` (after `holdRifle`), item `shieldpistol` (`ITEMS.*.shield`); the shield soldier's arm is `jackalArm` in the enemy `emixPost`. Test: test36.
- **Audit and its fixes (v32):** `audit/REPORT.md` scores every feature and lists the bugs; fixes come in batches (BACKLOG → Audit fixes). `tools/audit/` has the real-input scripts (`controls.mjs` key-in-state matrix, `bughunt`, `systems-a/b`, `verify*.mjs`, `perf.mjs`, `run_suites.sh`); they share `tools/audit/lib.mjs`. Rules from the fixes: a swing whose overlay is faded or replaced is over (the heal in `updateCombat`), so don't rely on `onDone` callbacks surviving `stopOvr()`; `releaseHeld()` lets go of everything on blur and pointer unlock; `sever()` copies only the soldier's own SkinnedMesh materials (tag extra skinned meshes with `userData.aura`); the world edge is ±1950 m in `step()`. Hook `redPieces()` counts pieces painted with gore. Infinite jumps start off (`v32-jumps`); `VARIETY` slots tick up to three variants (`v32-variety`). v33: special soldiers decide block/hit once per swing (`D.swing`, `jugg.swing`, `jackal.swing`, keyed on the `atk`/`thrown`/`dash` object); `turnCapped` limits how fast the shield soldier and duellist turn; `prewarm()` (end of `boot`) compiles guns, throwables, the arc, tracers, sparks, gore and splats; blood splats use `splatMaterial()` (atlas `build/fx_splat.png`). Test: test38.
- **Player look (v34):** `build/hero_dressed.glb` (from `node tools/dress_hero.mjs <Quaternius outfits zip>`) is the Superhero plus the Ranger outfit on the same skin (nodes named `outfit_*`; the bare body is split into head and rest primitives). `heroLook` / `applyLook(root, look)` / `setHeroLookPref` pick what shows; `heroAura` is an array of shells. Pause: `paused`, `setPause(on)`, `settings` (`localStorage.settings`: sens, invertY, vol, fov; `applySettings`), `BASE_FOV` is now a `let`. Sound: every clip goes through `audio.master` (the volume); `sfx(name, at, vol, delay)`; `footsteps(dt)`, `jetSound()`; hooks `sfxLog`, `sfxCount`, `sfxLoaded`. Tests: test40 (pause), test41 (roads), test42 (sounds).
